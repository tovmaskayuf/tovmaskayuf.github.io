# Essenta PRO — preview build

This repository holds a **built static preview** of an unfinished website, published so it can
be reviewed at a stable link. It is generated output only: no source, no content files, no
build tooling.

**The content is not final and is not approved.** Product copy, product facts and legal text
are placeholders, and the Armenian and Georgian translations are machine-drafted and have not
been read by a native speaker. Nothing here should be quoted, indexed, or treated as a
statement by the brand.

Every page ships `noindex, nofollow` and `robots.txt` disallows all crawling, deliberately.

This repository is temporary and will be deleted once the review is over.
